+     ```vue
+     <script setup lang="ts">
+     import { CopilotKitProvider } from "@copilotkit/vue/v2";
+     import { standardUI, type GenerativeUITheme } from "@copilotkit/vue/v2/generative-ui";
+     const theme: GenerativeUITheme = {
+       "--a2ui-color-accent": "#d97706",
+       "--a2ui-font-family": "Inter, sans-serif",
+       "--a2ui-radius-md": "10px",
+     };
+     </script>
+     <template>
+       <CopilotKitProvider runtime-url="/api/copilotkit" :generativeUI="{ ui: standardUI, theme }">
+         <slot />
+       </CopilotKitProvider>
+     </template>
+     The binding is reactive. Keep `theme` in a `ref`, and the surfaces update when you change it.
+ <Callout type="info" title="React Native">
+   React Native has no standard catalog and no CSS variables, so its `GenerativeUIProvider` has no `theme` prop: passing one is a type error, and a `theme` passed from JavaScript, or through a cast, is dropped, with a warning in development. Style the components of your own catalog with `StyleSheet`, as you style the rest of your app. See [Generative UI with your own components](/langgraph-typescript/react-native#generative-ui-with-your-own-components).
+ </Callout>
